# Config notes (necessary only)

Defaults are the pack unless a row below says otherwise. Do not dump every mod’s full config into git.

Minecraft, loader, and pack version: see [`pack/pack.toml`](../../pack/pack.toml).

| Mod | Touch? | Note |
|---|---|---|
| Java 21 JVM flags | Pack overlay | `pack/user_jvm_args.txt` (`-XX:+UseZGC`). `python scripts/update_prism.py` copies those flags into Prism `instance.cfg`. Dedicated NeoForge uses `server/run.sh`. Mrpack/CurseForge cannot auto-apply launcher JVM args. Do not add `-XX:+ZGenerational`. |
| Sodium Extra + More Culling | After first boot | Both can simplify/cull leaves. Disable Extra’s reduced-leaves option **or** More Culling’s leaf culling so they do not stack. Do not add Sodium Leaf Culling, OptiLeaves, or Chloride. |
| Create: Threaded Trains | Defaults | Offloads train calculation. Create addons that patch trains can freeze; test trains before adding those addons. |
| FTB Quests Optimizer | Defaults | File `3.2.0` is older than FTB Quests `2101.1.36`. If quest ticks misbehave, remove the optimizer first. |
| Bye?Pregen! | Defaults | Do not re-add Noisium or AntiXRay. Fast Noise did not raise Tectonic-era CPS; do not add it for that. Do not stack Fast Noise with RTF. Chunk Pregenerator stays for operator pregen. |
| Lithostitched | Defaults | Regions Unexplored's eight `in_structure` placed features are overridden by `pack/global_packs/required_data/lead-leylines-ru-in-structure/`. Do not remove that datapack while RU and Lithostitched are both in. |
| Global Packs | `pack/config/global_packs.toml` | `config_version = 3` (jar default). `datapacks.required` includes `global_packs/required_data/`. `enable_system_global_packs` stays false. Unpacked datapack only; packwiz ignores `*.zip`. Required datapacks: `lead-leylines-ru-in-structure/`, `lead-leylines-large-climate/`, `lead-leylines-nether-pixies/`, and `lead-leylines-orphan-loot/`. |
| Terralith | `pack/config/terralith.json` | `modules.terrain_slabs = false` so Terralith's overlay does not stack slabs with Countered's Terrain Slabs. Skylands stay on. Feature Recycler is the feature-order-cycle fix, not this toggle. Climate size is the Global Packs datapack below, not this file. |
| TerraBlender | `pack/config/terrablender.toml` | `overworld_region_size` / `nether_region_size` / End biome sizes are **6** (max). Each biome mod (Terralith, OTBWG, RU, vanilla) gets large continents instead of small mixed patches. Vanilla region **weight** stays 10. New world required. Do not use the Large Biomes world type with Terralith. |
| Large climate datapack | `pack/global_packs/required_data/lead-leylines-large-climate/` | Overrides Terralith's `minecraft:temperature` / `minecraft:vegetation` noise: `firstOctave` matches vanilla Large Biomes (-12 / -11) so individual biomes inside a TerraBlender region are about 4x larger. High-frequency amplitudes are halved so climate speckle is a bit smoother. Applies to `minecraft:overworld` (Terralith, OTBWG, RU, YUNG cave biomes). Does not change terrain shape (continentalness / erosion stay Terralith). New world required. |
| Alex's Caves Continued | `pack/config/alexscaves-general.toml` | `[generation]`: `cave_biome_mean_width` **700** (default 300), `cave_biome_mean_separation` **1600** (default 900), slightly rounder / more even spacing. Bigger caves that sit farther apart. New world required. |
| Ecliptic Seasons | Defaults | Solar-term seasons. Bundles + MultiMod Patch in. Do not add Serene Seasons next to the API stub. Do not re-add Voxy Compact (or Make it compatible) to packwiz; they crash without a local `voxy-forged` jar. |
| Ice and Fire pixie villages | `pack/global_packs/required_data/lead-leylines-nether-pixies/` | Replaces `iceandfire:structure_gen/pixie_village` with `#minecraft:is_nether` (and optional `#c:is_nether` for modded Nether biomes). Pixies only spawn from those villages. New Nether chunks required; already-generated Overworld villages stay. |
| Orphan loot tables | `pack/global_packs/required_data/lead-leylines-orphan-loot/` | Replaces loot tables that reference unregistered items with empty tables: Mekanism More Machine Evolved-tier factories (dense/overclocked/quantum/multiversal/creative — jar ships them; blocks only register if Evolved Mekanism is present), Mekanism Extras chemical-infusing factories, and ExtendedAE `ex_emc_interface` (ProjectE soft-dep). Stops boot `Couldn't parse … loot_table` spam. Do not add Evolved Mekanism or ProjectE just to clear these. |
| WorldWeaver / BCLib (BetterNether New Dawn) | `pack/config/wover/client.json`, `pack/config/bclib/client.json` | Welcome / BetterX setup screens dismissed (`did_present_welcome_screen`, `didShowWelcome`). Update checks and force-BetterX world preset off so Terralith / TerraBlender world create stays the default. |
| Feature Recycler | Defaults | Required while Terralith and Oh The Biomes We've Gone are both in. Server-logic, so packwiz `both`. |
| Cerulean | Defaults | Do not re-add Achievements Optimizer. |
