# Config notes (necessary only)

Defaults are the pack unless a row below says otherwise. Do not dump every mod’s full config into git.

Minecraft, loader, and pack version: see [`pack/pack.toml`](../../pack/pack.toml).

| Mod | Touch? | Note |
|---|---|---|
| Tooltip Overhaul | `pack/config/tooltipoverhaul/` | `custom_frames.json` is merged with the jar's showcase frames. Type and material tags are priority 100 (specific tags first), content-mod namespaces are priority 50, and rarity is priority 10. `tooltipoverhaul.toml` sets `general.ALWAYS_SHOW_COMPARISON` to false. The compare key is unbound in `pack/config/defaultoptions/keybindings.txt` so shift-compare stays Equipment Compare. Hold Tag Tooltips' semicolon key to list tags inside the frame. |
| Keybinds | `pack/config/defaultoptions/keybindings.txt` | Default Options applies these when a key is still on the mod's original default. **M** is only Xaero's world map (`gui.xaero_open_map`). FTB Chunks map is F8. Xaero's new-waypoint is F10 so B stays Open Backpack. Reload stays R for TaCZ and Point Blank. Iris shader reload and the shader toggle are unbound (they were R and K). Epic Fight mode is grave (`` ` `` / `~`), dodge is C, lock-on is T. ParCool dodge / breakfall / wall run share left Alt; ParCool crawl stays C. TaCZ prone is Z. TaCZ zoom is middle mouse. Ultimine is Tab (the player list is also Tab). Fire select is J, Point Blank scope switch stays period, refit is `[`. Curios stays G. Ars spellbook is right Alt. |
| Java 21 JVM flags | Pack overlay | `pack/user_jvm_args.txt` (`-XX:+UseZGC`). `python scripts/update_prism.py` copies those flags into Prism `instance.cfg`. Dedicated NeoForge uses `server/run.sh`. Mrpack/CurseForge cannot auto-apply launcher JVM args. Do not add `-XX:+ZGenerational`. |
| Sodium Extra + More Culling | After first boot | Both can simplify/cull leaves. Disable Extra’s reduced-leaves option **or** More Culling’s leaf culling so they do not stack. Do not add Sodium Leaf Culling, OptiLeaves, or Chloride. |
| Create: Threaded Trains | Defaults | Offloads train calculation. Create addons that patch trains can freeze; test trains before adding those addons. |
| FTB Quests Optimizer | Defaults | File `3.2.0` is older than FTB Quests `2101.1.36`. If quest ticks misbehave, remove the optimizer first. |
| Bye?Pregen! | Defaults | Do not re-add Noisium or AntiXRay. Fast Noise did not raise Tectonic-era CPS; do not add it for that. Do not stack Fast Noise with RTF. Chunk Pregenerator stays for operator pregen. |
| Lithostitched | Defaults | Regions Unexplored's eight `in_structure` placed features are overridden by `pack/global_packs/required_data/lead-leylines-ru-in-structure/`. Do not remove that datapack while RU and Lithostitched are both in. |
| EMF | `pack/config/entity_model_features.json` | `modelsNamesDisabled` lists the mobs Epic Fight animates (skeleton, zombie, spider, illagers, and the rest of that set, including baby and outer layers). Fresh Animations and Darkest Ages stay on for other mobs. Do not re-enable those names while Epic Fight is in; the custom model parts are not Epic Fight bones, so skeletons render as floating pieces and a missing-texture plane. |
| Global Packs | `pack/config/global_packs.toml` | `config_version = 3` (jar default). `datapacks.required` includes `global_packs/required_data/`. `enable_system_global_packs` stays false. Unpacked datapack only; packwiz ignores loose `*.zip` files. Required datapacks: `lead-leylines-ru-in-structure/`, `lead-leylines-large-climate/`, `lead-leylines-nether-pixies/`, `lead-leylines-nether-fire-dragons/`, `lead-leylines-orphan-loot/`, `lead-leylines-no-vanilla-stone/`, and `lead-leylines-load-fixes/`. Required resource packs, in load order: Fresh Animations, its Extensions, Darkest Ages Mobs, Darkest Ages + Fresh Animations, Icon Xaero's, Enhanced Boss Bars. |
| Terralith | `pack/config/terralith.json` | `modules.terrain_slabs = false` so Terralith's overlay does not stack slabs with Countered's Terrain Slabs. `vanilla_stone_gen` stays false. Skylands stay on. Feature Recycler is the feature-order-cycle fix, not this toggle. Climate size is the Global Packs datapack below, not this file. |
| Disabled vanilla stone blobs | `pack/global_packs/required_data/lead-leylines-no-vanilla-stone/` | Removes `minecraft:ore_andesite_*`, `ore_diorite_*`, and `ore_granite_*` from overworld biome lists, plus Terralith skylands, Terralith deep warm ocean, Alex's Caves, and Ars Elemental. Those Terralith biomes are not in `#minecraft:is_overworld`. Terralith already sets those placed features to count 0; JEI WorldGen still logged `Missing data` because that stub has no height range. Andesite, diorite, and granite keep coming from Terralith. Leave `vanilla_stone_gen` off while this datapack is in. |
| TerraBlender | `pack/config/terrablender.toml` | `overworld_region_size` / `nether_region_size` / End biome sizes are **6** (max). Each biome mod (Terralith, OTBWG, RU, vanilla) gets large continents instead of small mixed patches. Vanilla region **weight** stays 10. New world required. Do not use the Large Biomes world type with Terralith. |
| Large climate datapack | `pack/global_packs/required_data/lead-leylines-large-climate/` | Overrides Terralith's `minecraft:temperature` / `minecraft:vegetation` noise: `firstOctave` matches vanilla Large Biomes (-12 / -11) so individual biomes inside a TerraBlender region are about 4x larger. High-frequency amplitudes are halved so climate speckle is a bit smoother. Applies to `minecraft:overworld` (Terralith, OTBWG, RU, YUNG cave biomes). Does not change terrain shape (continentalness / erosion stay Terralith). New world required. |
| Alex's Caves Continued | `pack/config/alexscaves-general.toml` | `[generation]`: `cave_biome_mean_width` **700** (default 300), `cave_biome_mean_separation` **1600** (default 900), slightly rounder / more even spacing. Bigger caves that sit farther apart. New world required. |
| Ecliptic Seasons | Defaults | Solar-term seasons. Bundles + MultiMod Patch in. Do not add Serene Seasons next to the API stub. Do not re-add Voxy, Voxy Server Side, Forgified Fabric API, Voxy Compact, or Make it compatible. |
| Structurify | `pack/config/structurify.json` | Global spacing and separation multiplier is **2.0** (vanilla is 1.0). Applies to structure sets that use Minecraft random spread. Mods with their own placement, such as Lost Cities, keep their own spacing. New chunks required. |
| Ice and Fire | `pack/config/iceandfire/iaf-common.json` | `dragon.generate.skeletons` is **false**. That turns off the worldgen feature that places already-dead dragons. Killing a dragon still leaves a harvestable corpse. Other keys in that file are the 2.1.3 defaults. |
| Ice and Fire pixie villages | `pack/global_packs/required_data/lead-leylines-nether-pixies/` | Replaces `iceandfire:structure_gen/pixie_village` with `#minecraft:is_nether` (and optional `#c:is_nether` for modded Nether biomes). Pixies only spawn from those villages. New Nether chunks required; already-generated Overworld villages stay. |
| Ice and Fire fire dragons | `pack/global_packs/required_data/lead-leylines-nether-fire-dragons/` | Replaces `iceandfire:structure_gen/fire` with `#minecraft:is_nether` (and optional `#c:is_nether`). Fire dragon roosts and caves use that tag. Ice and lightning dragons stay on their own tags. New Nether chunks required; already-generated Overworld fire roosts and caves stay. |
| Orphan loot tables | `pack/global_packs/required_data/lead-leylines-orphan-loot/` | Replaces loot tables that reference unregistered items with empty tables: Mekanism More Machine Evolved-tier factories (dense/overclocked/quantum/multiversal/creative — jar ships them; blocks only register if Evolved Mekanism is present), Mekanism Extras chemical-infusing factories, and ExtendedAE `ex_emc_interface` (ProjectE soft-dep). Stops boot `Couldn't parse … loot_table` spam. Do not add Evolved Mekanism or ProjectE just to clear these. |
| Load fixes | `pack/global_packs/required_data/lead-leylines-load-fixes/` | My Nether's Delight bastion injections use Farmer's Delight's `table` field. Terralith caves, gravel desert, and the four savannas move from Ecliptic Seasons' deprecated rain tags onto `rain/rainless`, `rain/arid`, and `rain/monsoonal`; the old tags are cleared. Regions Unexplored ocelots in eucalyptus forest, rainforest, sparse rainforest, and tropics spawn as creatures (weight 2). YUNG's sand snapper in lost caves spawns as a monster (weight 50, 1–2). Jaden's Nether Expansion recipes for `warphopper_fur`, `iron_scrap`, `igneous_reeds`, and `indented_soul_slate_tiles` are disabled; those items are not registered. Aquamirae's scuttler stays on the creature list in deep cold and deep frozen oceans: the mod adds that spawn in code after datapack biome modifiers. |
| WorldWeaver / BCLib (BetterNether New Dawn) | `pack/config/wover/client.json`, `pack/config/bclib/client.json` | Welcome / BetterX setup screens dismissed (`did_present_welcome_screen`, `didShowWelcome`). Update checks and force-BetterX world preset off so Terralith / TerraBlender world create stays the default. |
| Feature Recycler | Defaults | Required while Terralith and Oh The Biomes We've Gone are both in. Server-logic, so packwiz `both`. |
| Cerulean | Defaults | Do not re-add Achievements Optimizer. |
| Vic's Point Blank | `pack/pointblank/` | Content-pack zips are packwiz CurseForge metadata in this folder (instance `pointblank/`, both sides). Do not commit the zips. Alt+Y opens the content-pack menu. If Iris blurs guns or picture-in-picture scopes, use the non-PIP scope option in that menu. Interaction ships both so the `pointblank_passthrough:interaction` channel exists on the server. The server-mods zip drops the class-level client-only marker on `InteractionManager` and replaces that class's client-only method bodies (`scripts/patch_pointblank_interaction.py`). The CurseForge client jar is unchanged. Config load and the server interaction checks call this class; the marker, and the `LocalPlayer` references in the client methods, crash a dedicated server. `pack/config/pointblank_passthrough_interaction-common.toml` sets `interaction.enable_debug_logging` to false. The mod default is true, which logs every non-gun interaction. |
| TaCZ Tactical Breaching | `pack/config/tacz_tactical_breaching-common.toml` | `distant_gunshots.debugDistantGunshots` is false. The mod default is true, which logs every distant echo. Echoes stay on. Other keys stay the mod defaults. |
| TaCZ gun packs | `pack/tacz/` | Packwiz CurseForge metadata for the instance `tacz/` folder, both sides, so Pack Upgrader can read them. MCS2 zip, Daffa's Arsenal 3.7.1.1 jar, and CS+ 1.3.1. Do not put those 1.20.1 files in `mods/` (Forge loader, wrong version). CS+ is the CurseForge jar saved as `.zip`: the upgrader only lifts jars that contain `addon/` or `assets/*/gunpack`, and CS+ keeps `gunpack.meta.json` at the archive root. MCS2Gun-addon `1285238` is not installed: no 1.21.1 file, and the 1.20.1 jar is an encrypted Forge mod the upgrader quarantines without registering guns. Warzone 1.1.8B is out: its models and textures live in `recursion/taczpack.dat`, and this TaCZ port does not read that archive, so every Warzone item was a missing texture. |
