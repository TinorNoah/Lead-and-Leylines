# Structures

Dungeons, villages, and the tools that space or label them. Boss arenas that belong to one boss mod are in [Bosses](bosses.md). Nether-only structures are in [The Nether](nether.md).

Each mod is listed once. Decision notes stay in [`docs/mods/`](../mods/manifest.md).
