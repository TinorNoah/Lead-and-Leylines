# Automation

Extra machine mods beside Create and Mekanism. Pipes and routers are in [Transport](transport.md). Applied Energistics is in [Applied Energistics](applied-energistics.md).

Each mod is listed once. Decision notes stay in [`docs/mods/`](../mods/manifest.md).
