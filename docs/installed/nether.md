# The Nether

Nether biomes, structures, and mobs. Nether foods are listed with [Food](food.md). Lithostitched, which Infernal Expansion also uses, is listed with the overworld biome packs in [Biomes](biomes.md).

Each mod is listed once. Decision notes stay in [`docs/mods/`](../mods/manifest.md).
