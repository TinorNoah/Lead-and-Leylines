# The End

End biomes and the End expansion. The rebuilt central dragon-fight island is here too.

Each mod is listed once. Decision notes stay in [`docs/mods/`](../mods/manifest.md).

## The End

| Mod | File | Side | Tags | What it adds |
|---|---|---|---|---|
| Unusual End | `unusualend-2.3.1b.jar` | both | `core`, `worldgen`, `end`, `world-data` | End biomes, mobs, and structures. |
| Blueprint | `blueprint-1.21.1-8.2.0.jar` | both | `library`, `worldgen`, `end` | Library Unusual End and Neapolitan need. |
| Nullscape | `Nullscape_1.21.x_v1.2.14.jar` | both | `core`, `worldgen`, `end`, `world-data` | End islands and biome look. |

| Awesome Dungeon The End edition - Neoforge | `awesomedungeonend-neoforge-1.21.1-3.1.1.jar` | both | `addon`, `structure`, `worldgen`, `end`, `world-data` | Dungeons in the End. |
