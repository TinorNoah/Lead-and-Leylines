Mostly Modrinth `+mod` suffix / Cosmic Reach-style version string mismatches (`create` 6.0.10 vs `6.0.10+mc1.21.1`, Farmer’s Cutting / Epic Structures datapacks). Treat as checker noise unless a real newer file exists on CurseForge.

Smoke harness sets offline — ignore.

### ModernFix

Several mixins forced off by C2ME; datapack load 53s; dedicated load ~212s (matches ~193s boot metric).

### JarJar duplicate Kotlin / nested deps

### DeferredWorkQueue slow mods

`tacz` ~3.7s, `biomeswevegone` ~2.7s, `fdlib` ~1.9s, `apothic_attributes` ~1.2s.

### Memory oddity
